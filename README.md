## 🚀 Overview
This project focuses on building a **Spam Email Detection System** using **TensorFlow** and Python.  
It uses machine learning techniques to classify emails as **Spam** or **Ham (Not Spam)**.

The model is trained on text data and learns patterns commonly found in spam emails to make accurate predictions.

---

## 🎯 Features
- 📌 Spam vs Ham email classification  
- 📊 Text preprocessing and cleaning  
- 🧠 Machine Learning model using TensorFlow  
- ⚡ Fast and efficient predictions  
- 📁 Easy-to-understand code structure
